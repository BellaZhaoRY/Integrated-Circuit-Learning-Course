1.1> 格式字符

格式字符

对应数据类型

含义

%c

char

字符型，输入的数字按照ASCII码相应转换为对应的字符

%hd

short

短整数

%hu

unsigned short

无符号短整型

%d

int

有符号10进制整数， %6d， %-6d， %06d，

%u

unsigned int

无符号10进制整数

%f

float

单精度浮点数, %.2f, 2位小数位

%lf

double

双精度浮点数

%E

doubel

指数形式打印， 1.234567e+02

%s

char *

字符串

%p

void *

以16进制形式输出指针， %#p

%x

unsigned int

无符号16进制 整数

%hx

unisigned short

无符号16进制 短整型
