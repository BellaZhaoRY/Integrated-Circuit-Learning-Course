课程名称：从大模型到具身智能：原理与仿真实践


第一部分：告别“无身”AI——什么是具身智能？

1.1 熟悉的AI vs. 机器人

我们日常接触的AI（大语言模型、图像识别）通常是“无身”的（Disembodied）。

  • 图像识别：输入是像素矩阵，输出是类别标签。
  • 大语言模型：输入是Token序列，输出是Token序列。
  • 特点：它们不需要承受重力、摩擦或碰撞。即便输出错误（幻觉），也不会导致机器物理损坏。

1.2 机器人的因果链

机器人引入了物理因果：

  • 语言模型：文字 → 模型 → 文字
  • 机器人：传感器 → 决策 → 电机 → 身体 →环境
  • 后果：如果决策输出错误动作，会导致摔倒、碰撞或硬件烧毁。

1.3 具身智能的定义

具身智能（Embodied AI）不仅仅是大脑，它包含五个不可分割的部分：

  1. 身体（Body）：机械结构、连杆、关节。
  2. 环境（Environment）：地面摩擦系数、障碍物、重力场。
  3. 感知（Perception）：关节编码器（位置）、IMU（姿态/加速度）、相机、触觉传感器。
  4. 决策（Decision）：规则（Rule-based）、控制器（Controller）、神经网络策略（Policy Network）。
  5. 行动（Action）：电机扭矩、舵机角度、轮子转速。

核心洞察：

智能不只存在于“大脑”中。身体形态（腿长、脚掌大小）、关节结构（自由度配置）和环境约束（重力）共同参与了行为的形成。

例如：脚掌太小、质心太高或电机扭矩不足，再好的算法也无法让机器人稳定行走。

2.2 开环 vs. 闭环

  • 开环控制 (Open-Loop)：
  • 提前写好动作序列（如：抬腿30度，停顿0.5秒，落下）。
  • 执行时不关心实际结果。
  • 比喻：闭着眼睛沿直线走路，撞墙了也不知道。



  • 闭环控制 (Closed-Loop)：
  • 每一帧根据实际状态反馈修正动作。
  • 比喻：睁着眼睛走，看到偏左就往右修。
  • 必要性：机器人必须依赖闭环控制来抵抗扰动（如被推了一下）。

第三部分：具身智能系统的层次结构

我们可以将复杂的控制系统分为三层：

  1. 任务层 (Task Layer)：
  • 目标：“向前走”、“左转90度”、“停下来”。
  • 这是人类下达指令的层级。
  1. 规划/策略层 (Planning/Policy Layer)：
  • 目标：为了实现“向前走”，下一步躯干如何摆动？脚落在哪里？
  • 对应强化学习中的Policy，或传统控制中的轨迹规划器。
  1. 底层控制层 (Low-level Control Layer)：
  • 目标：为了达到规划的姿势，膝关节具体转到多少角度？电机输出多大扭矩？
  • 对应PID控制器或力矩控制器。

3.1 传统方法与学习方法的结合

  • 传统方法：工程师手动设计运动学方程、动力学模型和控制律（如PID、MPC）。
  • 学习方法：让策略在仿真中通过试错（如强化学习）学习从观测到动作的映射。
  • 现状：二者并非对立。纯强化学习的步态往往像“咕咕鸡”（姿态丑陋、效率低），通常需要引入参考动作（Reference Motion）或传统控制先验，才能让机器人走得像人。真实系统中，往往是“学习策略负责高层意图，传统控制负责底层稳定和抗扰”。

第四部分：平衡的物理原理（为什么站着也是技术活？）

即使人静止站立，身体也在微调。这是因为重力与支撑力的博弈。

单脚站立闭眼，体会肌肉高频微颤，理解“不动之动”。

4.1 质心 (Center of Mass, CoM)

  • 质心不是几何中心，而是全身质量加权平均的位置。
  • 重力作用于质心，方向竖直向下。
  • 支持力作用于足底，方向向上。

​

4.2 质心投影与支撑区域 (Support Polygon)

从质心向地面作垂线，得到质心投影。

  • 支撑区域：所有支撑脚与地面接触点构成的凸多边形。
  • 静态平衡：质心投影落在支撑区域内，机器人不易倾倒。
  • 双脚站立：支撑区域大，稳定。
  • 单脚站立：支撑区域缩小为一条线或一个面，极难维持平衡。
  • 动态考量：高速运动时，不能仅看静态投影，还需考虑惯性力和角动量。

4.3 动态平衡：倒立摆与 Capture Point

机器人跌倒往往不是因为位置偏了，而是因为速度太快。

  • 危险情况：倾角小，但角速度极大（正在快速倒下）。
  • 安全情况：倾角大，但角速度为负（正在回正）。
  • Capture Point (捕捉点) 直觉：

如果身体已经有了倾倒速度，脚必须落在质心投影的前方（速度越快，落点越远），才能像“接球”一样把身体的动能抵消掉。这就是动态步行（Dynamic Walking）的核心思想。

6.2 仿真器在计算什么？


MuJoCo 在每一个时间步 Δt 内求解牛顿第二定律 (F=ma)：

  1. 物理属性：质量、转动惯量、关节阻尼。
  2. 状态变量：当前关节位置 (q)、速度 (q˙)。
  3. 外力：重力、执行器施加的力/扭矩。
  4. 接触动力学：碰撞检测、摩擦力、约束求解。
  5. 积分：计算加速度 (q¨)，更新速度和位置。

6.3 连续世界与离散时间步

真实世界是连续的，但计算机是离散的。

  • 时间步长 (Δt)：
  • 太大：计算快，但容易穿透物体或不稳定（发散）。
  • 太小：精度高，但计算量大。
  • 控制频率 vs. 物理频率：
  • 物理仿真频率：通常很高（如 500Hz，即 Δt=0.002s）。
  • 控制策略频率：通常较低（如 50Hz，即 0.02s）。
  • 关系：每输出1次控制指令，物理引擎内部可能已经计算了10步。

课程总结

  1. 具身性：智能是身体、环境、感知、决策和行动的整体。
  2. 非动画：机器人控制是实时闭环反馈，而非播放预录动画。
  3. 交互性：行动改变环境，环境改变观测，这是一个动态耦合的过程。
  4. 软硬结合：优秀的机器人系统 = 合理的机械设计 + 鲁棒的控制算法。
