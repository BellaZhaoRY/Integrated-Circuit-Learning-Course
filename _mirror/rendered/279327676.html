1. 什么是 URDF

URDF (Unified Robot Description Format) 是 ROS 中用于描述机器人模型的 XML 格式文件。它定义了：

  • Link（连杆）：机器人的刚体部分（如大腿、小腿、躯干）
  • Joint（关节）：连接两个 Link 的运动副（如髋关节、膝关节）
  • Material（材质）：外观颜色 给人看的
  • Inertial（惯量）：物理属性（质量、转动惯量） sim2real非常关键 系统辨识

本教程将带你从零创建一个简单的双足机器人模型。

5.3 标签详解

<visual>：视觉属性

  • <origin xyz="x y z" rpy="roll pitch yaw">：几何体的位置和姿态
  • xyz：相对于 Link 坐标系的平移（单位：米）
  • rpy：绕 X/Y/Z 轴的旋转（单位：弧度）
  • <geometry>：几何体形状
  • <box size="x y z">：长方体
  • <cylinder radius="r" length="l">：圆柱
  • <sphere radius="r">：球体
  • <material>：引用前面定义的材质

<inertial>：物理属性（非常重要！）

  • <mass value="8.0"/>：质量（kg）
  • <inertia>：转动惯量矩阵（kg·m²）
  • 对于长方体：Ixx = m(y²+z²)/12
  • 对于圆柱：Ixx = Iyy = m(3r²+l²)/12

💡 小技巧： 如果不懂惯量计算，可以先用在线计算器，或参考类似物体的数值。

9. 常见问题与调试

❌ 问题1：模型不显示

原因： XML 语法错误

解决： 检查xml开始闭合标签

❌ 问题2：Link 漂浮在空中

原因：<origin> 坐标计算错误

解决： 检查父 Link 的尺寸和关节位置

❌ 问题3：关节旋转方向反了

原因：<axis> 方向错误

解决： 尝试改变 axis 的正负号，如 xyz="0 -1 0"
