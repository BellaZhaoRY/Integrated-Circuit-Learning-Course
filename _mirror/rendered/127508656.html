训练

训练一个 深度学习 模型涉及向其输入数据并调整其参数，以便它能做出准确的预测。Ultralytics YOLO26 中的训练模式专为高效、有效地训练目标检测模型而设计，充分利用了现代硬件性能。本指南旨在涵盖你开始使用 YOLO26 强大的功能集训练自己的模型所需的所有细节。

​

以下是选择 YOLO26 训练模式的一些令人信服的理由：

  • 效率： 无论你是在单 GPU 设置下还是在多 GPU 环境中扩展，都能充分利用你的硬件性能。
  • 多功能性： 除了 COCO、VOC 和 ImageNet 等现成数据集外，还支持使用自定义数据集进行训练。
  • 用户友好： 简单而强大的 CLI 和 Python 接口，可提供直接的训练体验。
  • 超参数灵活性： 提供广泛的可自定义超参数以微调模型性能。如需更深入的控制，你可以自定义训练器。
  • 云训练： 通过 Ultralytics Platform 在云端 GPU 上进行训练，并获取实时指标和自动检查点保存功能。

参数解读（相比默认值，我做了这些加强）：

  • epochs=300：增加迭代轮数，给小模型更多机会“消化”增强后的样本。
  • lr0=0.001：降低初始学习率，避免在极小数据集上震荡或过拟合。
  • 几何增强：degrees=10.0（旋转）、translate=0.2（平移）、scale=0.5（缩放）、shear=5.0（剪切）、perspective=0.0005（透视）、flipud=0.5（上下翻转）、fliplr=0.5（左右翻转）——强制模拟不同角度和位置。
  • 拼接与混合：mosaic=0.5（马赛克增强，概率50%）、mixup=0.2（混合增强，概率20%），创造虚拟多目标场景。
  • copy_paste=0.0：对小数据集不建议开启，容易把物体粘贴到不合理的背景。

⚠️ 注意：这些增强参数可能让训练变得缓慢，且loss波动较大，这很正常。如果显存不足，可以调低 batch 大小（默认16，可改为8或4）。

​

增加了上面这些参数之后，它会在原有的数据集基础上无中生有创建一些图片出来，相当于是扩充了我们原来的数据集
