打开Settings - Editor...

左侧选中Keyboard shortcuts选项卡

设定代码格式化快捷键

下例将代码格式化快捷键设定为Alt+Shift+F

首先按照开头的教程，打开快捷键设置菜单，然后按照如下顺序进行设置：

  1. 点开Plugins
  2. 点击Source code formatter (AStyle)
  3. 点击 New shortcut 输入框同时按下：Alt + Shift + F 三个按键
  4. 点击Add
  5. 点击Ok
