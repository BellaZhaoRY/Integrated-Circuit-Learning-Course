第一车间：点火系统与中央大脑（核心系统区）

这是整个系统最底层的灵魂，相当于电脑的 BIOS 和 Windows 内核。

  • brandy/ (点火钥匙)： 里面装的是 Bootloader（U-Boot 等）。
  • Windows 类比： 相当于 Windows 的引导管理器（C:\bootmgr）。当我们给 T113 板子上电的那一瞬间，最先跑的就是这里的代码，它负责把硬件唤醒，然后交棒给内核。
  • kernel/ (中央大脑)： 纯正的 Linux 内核源码。
  • Windows 类比： 相当于 Windows 的 ntoskrnl.exe 及核心系统文件。所有的进程调度、内存分配全靠它，这是系统真正的心脏。

🛠️ 第二车间：主板定制与外设驱动（硬件适配区）

我们自己画的主板（HM-T113-CORE），需要专门的驱动才能跑起来，这些代码都在这里。

  • bsp/ (主板驱动光盘)： 板级支持包（Board Support Package）。
  • Windows 类比： 就像你买了一块华硕主板，盒子里附带的那张“芯片组驱动光盘”。这里面放着专门针对我们这块开发板的底层配置。
  • platform/ & device/ (设备管理器)： 包含平台特定的驱动、硬件抽象层以及分区表配置。
  • Windows 类比： 相当于 Windows 的“设备管理器”配置（C:\Windows\System32\drivers）和 DirectX SDK。它们负责告诉系统：板子上挂了几个串口、有没有 MIPI 屏幕。

🏗️ 第三车间：自动流水线与零件库（构建与工具区）

这里是我们在 Ubuntu 电脑上执行编译动作时，真正发光发热的地方。

  • build.sh & build/ (总包工头与临时仓库)：build.sh 是一键编译脚本，build/ 存放编译时的临时文件。
  • Windows 类比： 相当于 Visual Studio 里的 Build.bat 批处理脚本，以及编译时产生的 obj/ 或 Intermediate/ 临时垃圾文件夹。
  • buildroot/ & openwrt/ (应用软件超市)： Tina Linux 是基于 OpenWrt 构建的，它们负责把各种好用的应用软件（比如网络工具、音频播放器）打包进系统。
  • Windows 类比： 相当于 Windows ADK 或者控制面板里的“启用或关闭 Windows 功能”。你要不要在系统里预装一个 Python？全在这里决定。
  • prebuilt/ & tools/ (现成零件与螺丝刀)： 存放提前编译好的第三方库和打包烧写工具。
  • Windows 类比： 相当于 Windows 预装的 VC++ 运行库（DLL 文件）以及 Windows SDK 开发工具集。

📦 第四车间：成品出库与隐藏彩蛋（输出区）

  • out/ (成品打包发货区)：
  • Windows 类比： 相当于 Visual Studio 编译成功后的 bin/Release/ 目录。
  • 实战意义： 这里是最激动人心的地方。我们敲下 pack 命令后，兵工厂一顿猛如虎的操作，最终生成的那个用来烧录到 SD 卡的 t113_linux_xxx.img 文件，就静静地躺在这个目录里等待被提取！
  • rtos/ (隐藏的协处理器)：
  • 实战意义： T113 芯片内部其实还藏着一颗极低功耗的 RISC-V 核心（玄铁 E907）。这个目录里的代码就是给那个小核跑实时操作系统的，类似于 Windows 的特殊实时扩展模块。

通过这种“车间化”的梳理，原本一头雾水的源码目录瞬间就变成了一条逻辑清晰的兵工厂流水线。
