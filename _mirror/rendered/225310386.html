协程

协程（Coroutine）是一种比线程更轻量级的并发编程模型，它通过协作式多任务（而非抢占式）实现高效的并发执行。以下是协程的核心概念解析：

协程是可暂停和恢复的执行单元，具有以下特征：

  • 用户态调度：由程序（而非操作系统）控制切换，无内核开销
  • 单线程内并发：多个协程共享同一个线程资源
  • 异步非阻塞：通过挂起（yield）避免等待时的CPU空转

核心优势

  • 高性能IO并发：单线程可处理数万网络连接（如Web服务器）
  • 无锁编程：避免多线程的竞态条件问题
  • 资源高效：内存消耗远低于线程

典型应用场景

  2. 异步IO操作：数据库访问、文件读写
  3. 事件驱动系统：GUI应用、游戏循环
  4. 数据流处理：生成器管道

作用

  • 调度协程的执行：将协程包装为可被事件循环管理的执行单元。如挂起，取消等操作

事件循环event_loop

作用

  • 中央调度器：管理和分配单线程的执行时间，驱动所有协程任务。
  • IO多路复用：监听外部事件（如socket读写、定时器），在就绪时恢复对应协程。

特点

  • 任务队列：维护待执行的 Task 集合
  • 事件监听：集成操作系统IO多路复用机制（如epoll、kqueue）
  • 生命周期控制：启动/停止整个异步程序

工作流程

  1. 从任务队列选取就绪的 Task
  2. 执行到 await 时挂起当前 Task，检查IO事件
  3. 当IO完成或定时器触发时，将关联的 Task 重新加入队列
  4. 重复上述过程直到所有任务完成

await

在Python协程中，当执行await表达式时，确实会交出当前协程的执行权，但需要准确理解这个过程的机制。以下是详细的解释：

1. await的核心行为

  • 交出控制权：await会暂停当前协程的执行，将控制权返回给事件循环(Event Loop)
  • 非阻塞：交出控制权后，事件循环可以立即调度其他就绪的协程运行
  • 自动恢复：当await后面的对象（awaitable）完成时，协程会从暂停点恢复执行

gather

在 Python 的 asyncio 库中，asyncio.gather() 是一个核心的并发控制函数，用于同时运行多个协程（Coroutine）或任务（Task），并统一管理它们的结果和异常。以下是它的详细作用解析：

核心功能

(1) 并发执行多个协程

  • 自动调度：将传入的协程或任务立即加入事件循环，实现真正的并发执行。
  • 无需手动创建任务：如果传入的是协程对象（如 coro()），gather() 会自动调用 asyncio.create_task() 进行包装。

(2) 统一等待所有结果

  • 阻塞当前协程：直到所有传入的任务完成。
  • 有序返回结果：结果列表的顺序与传入的协程顺序一致。

(3) 异常处理

  • 默认聚合异常：任一任务抛出异常时，gather() 会立即取消其他任务，并将异常传播给调用者。
  • 可选宽容模式：通过 return_exceptions=True 将异常作为结果返回，不中断其他任务。

Websockets通信

WebSocket 是一种基于 TCP 的双向通信协议，允许客户端和服务器在单个长连接上进行全双工通信（双向实时数据传输）。相比传统的 HTTP 请求（短连接、单向通信），WebSocket 更适合实时应用，如在线聊天、股票行情推送、游戏同步等。

[codeblock]

WebSocket 核心特点

  1. 持久连接：建立连接后，客户端和服务器可以随时互相发送消息，无需反复握手。
  2. 低延迟：数据实时传输，避免了 HTTP 轮询的开销。
  3. 跨域支持：可通过 wss://（WebSocket Secure）实现加密通信。
  4. 轻量级：协议头部比 HTTP 更小，减少带宽消耗。
