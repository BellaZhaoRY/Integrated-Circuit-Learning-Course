1. 模拟输入设置 (FM收音机与Line-in)

  • numid=27, name='FMINL Gain'
  • 功能：FM 收音机输入（左声道）模拟增益。
  • 可选值范围：0 ~ 1 （0: 0dB, 1: 增益提升）。
  • numid=34, name='FMINL Switch'
  • 功能：FM 收音机输入（左声道）通道开关。
  • 可选值范围：0 (关闭) / 1 (打开)。
  • numid=28, name='FMINR Gain'
  • 功能：FM 收音机输入（右声道）模拟增益。
  • 可选值范围：0 ~ 1。
  • numid=35, name='FMINR Switch'
  • 功能：FM 收音机输入（右声道）通道开关。
  • 可选值范围：0 (关闭) / 1 (打开)。
  • numid=29, name='LINEINL Gain'
  • 功能：线性音频输入（Line-In 左声道）模拟增益。
  • 可选值范围：0 ~ 1。
  • numid=36, name='LINEINL Switch'
  • 功能：线性音频输入（Line-In 左声道）开关。
  • 可选值范围：0 (关闭) / 1 (打开)。
  • numid=30, name='LINEINR Gain'
  • 功能：线性音频输入（Line-In 右声道）模拟增益。
  • 可选值范围：0 ~ 1。
  • numid=37, name='LINEINR Switch'
  • 功能：线性音频输入（Line-In 右声道）开关。
  • 可选值范围：0 (关闭) / 1 (打开)。

2. 模数转换器 (ADC / 录音/麦克风设置)

  • numid=5, name='ADC DRC0 Mode' / numid=7, name='ADC DRC1 Mode'
  • 功能：ADC1/2 , ADC3/4 录音动态范围控制模式（用于防止爆音或提升小声音）。
  • 可选值范围：枚举值，通常为 0 (关闭 Disable) / 1 (开启 Enable)。
  • numid=6, name='ADC HPF0 Mode' / numid=8, name='ADC HPF1 Mode'
  • 功能：ADC0/1 , ADC3/4高通滤波器模式（用于滤除录音时的风噪或低频底噪）。
  • 可选值范围：枚举值，通常为 0 (Disable) / 1 (Enable)。
  • numid=9, name='ADC1 ADC2 Swap' / numid=10, name='ADC3 ADC4 Swap'
  • 功能：交换录音通道 1/2 或 3/4 的数据顺序（左右声道互换）。
  • 可选值范围：0 (正常) / 1 (互换)。
  • numid=22, name='ADC1 Gain' / numid=23, name='ADC2 Gain' / numid=24, name='ADC3 Gain'
  • 功能：ADC 1/2/3（通常对应 MIC 1/2/3）模拟前端增益（PGA放大倍数）。如果录音声音太小，调大此值。
  • 可选值范围：0 ~ 31 （对应硬件不同的 dB 提升）。
  • numid=19, name='ADC1 Volume' / numid=20, name='ADC2 Volume' / numid=21, name='ADC3 Volume'
  • 功能：ADC 1/2/3 捕获数字音量调节。
  • 可选值范围：0 ~ 255 （默认通常在 160 左右）。
  • numid=13, name='MIC1 Input Select' / numid=14, name='MIC2 Input...' / numid=15, name='MIC3 Input...'
  • 功能：麦克风 1/2/3 硬件引脚输入模式选择（如单端输入/差分输入选择）。
  • 可选值范围：枚举类型（例如 0 表示 Single-ended单端, 1 表示 Differential差分）。
  • numid=31, name='MIC1 Switch' / numid=32, name='MIC2 Switch' / numid=33, name='MIC3 Switch'
  • 功能：麦克风 1/2/3 通道捕获开关。
  • 可选值范围：0 (关闭) / 1 (打开)。
  • numid=42, name='Input1 Mux' / numid=43, name='Input2 Mux' / numid=44, name='Input3 Mux'
  • 功能：录音通道信号源复用选择器。用于决定到底录取什么声音（例如录 MIC、录 LINE-IN 或录 FMIN）。
  • 可选值范围：枚举值（具体可通过 amixer contents 查看，通常有 MIC1, LINEIN, Mixer 等选项）。

3. 数模转换器 (DAC / 播放/音频输出设置)

  • numid=3, name='DAC DRC Mode'
  • 功能：DAC 播放动态范围控制模式（防破音）。
  • 可选值范围：枚举值（0: Disable, 1: Enable 等）。
  • numid=4, name='DAC HPF Mode'
  • 功能：DAC 播放高通滤波器模式。
  • 可选值范围：枚举值（0: Disable, 1: Enable 等）。
  • numid=16, name='DAC Digital Volume'
  • 功能：DAC 总体播放数字音量（主音量控制）。
  • 可选值范围：0 ~ 63（按您的 DTS，默认值为 63，即最大声）。
  • numid=17, name='DACL Volume' / numid=18, name='DACR Volume'
  • 功能：DAC 左/右声道数字音量微调。
  • 可选值范围：0 ~ 255 （按 DTS 默认值为 160）。
  • numid=25, name='LINEOUT Volume'
  • 功能：线性输出（Line-Out）模拟音量/增益。
  • 可选值范围：0 ~ 31 （按 DTS 默认值为 26）。
  • numid=11, name='LINEOUTL Output Select' / numid=12, name='LINEOUTR Output Select'
  • 功能：线性输出左/右声道信号源选择（例如直接输出 DAC 的声音，或者混合外部输入的声音）。
  • 可选值范围：枚举值（通常有 DACL/R, Mixer 等）。
  • numid=38, name='LINEOUTL Switch' / numid=39, name='LINEOUTR Switch'
  • 功能：线性输出左/右声道硬件开关。
  • 可选值范围：0 (静音关闭) / 1 (开启输出)。
  • numid=26, name='HPOUT Gain'
  • 功能：耳机输出模拟增益（控制插耳机时的硬件推力/音量）。
  • 可选值范围：0 ~ 7。
  • numid=40, name='HPOUT Switch'
  • 功能：耳机输出总开关。
  • 可选值范围：0 (关闭) / 1 (打开)。
  • numid=41, name='SPK Switch'
  • 功能：外放喇叭（Speaker）输出开关（通常控制板载 PA 功放使能引脚或芯片内部喇叭驱动）。
  • 可选值范围：0 (关闭) / 1 (打开)。

  • numid=1, name='rx sync mode'

录音配置

通常默认录音使用的是 MIC1 和 ADC1 通道（具体取决于你的板子硬件接线，如果是 MIC2 则对应 ADC2）。

要调整录音音量并优化音质，你需要综合调整 ADC（模数转换器数字端）、MIC（模拟增益端） 以及 DSP（滤波器） 配置。我们的T113板子，接的是ADC3

以下是具体的操作步骤和建议修改的配置项：

1. 调大录音音量 (Volume)

录音音量由模拟增益（MIC/ADC Gain）和数字音量（ADC Volume）共同决定。建议优先调大模拟增益，如果还不够，再调大数字音量。

提升模拟增益 (ADC1 Gain)（最关键）：
这是麦克风的硬件放大器。值越大声音越大，但调到极限（31）可能会引入底噪（沙沙声）。

[codeblock]

提升数字音量 (ADC1 Volume)：
这是在模拟信号转成数字信号后的软件放大。如果模拟增益已经很高但声音仍小，可以适当加大这个值。

[codeblock]

2. 优化音质 (Quality)

全志的 Codec 内置了硬件音频处理算法，开启它们可以大幅改善录音质量，特别是滤除环境底噪和防止声音过大导致的破音。

  • 开启高通滤波器 (ADC HPF0 Mode)：
    强烈建议开启。 它可以滤除低频的环境噪音（如风声、电流嗡嗡声、远处的马达声），让收音（尤其是人声）更干净。
[codeblock]
  • 开启动态范围压缩 (ADC DRC0 Mode)：
    如果你的录音场景是人声对话，建议开启。它会自动把小声音放大，把过大的声音压小，防止破音（Clipping）。（注：如果是录制高保真音乐，建议关闭以保留原始动态）。
[codeblock]
  • 麦克风输入模式 (MIC1 Input Select)：
    这点极其影响底噪。如果你的板子麦克风是差分接法（两根线 MIC1P, MIC1N），必须将其选为差分模式（Differential），这样抗干扰能力极强，几乎没有底噪。如果是单端接法，则选单端（Single-ended）。
[codeblock]

3. 确保通道和路由已正确开启 (Input/Switch)

总结建议调试流程：

  • 先开滤噪：amixer -D hw:audiocodec cset name='ADC HPF0 Mode' 1
  • 用你的 arecord 命令录一段话。
  • 如果声音太小，逐步调大 ADC1 Gain（例如从 20 调到 25，再到 28）。
  • 听录音文件，如果发现声音很大但是有“滋滋”的破音（失真），说明 Gain 调得太高了，降一点 Gain，然后把 ADC DRC0 Mode 设为 1。

麦克风录音方案

在嵌入式开发中，全志（Allwinner）T113 系列（如 T113-S3, T113-i）凭借其内置的 HiFi4 DSP 和丰富的音频接口，成为了智能语音、工业控制和车载多媒体的常用方案。

针对麦克风（录音）需求，以下是基于 T113 芯片最常见且稳定的四种技术解决方案：

1. 内置模拟 Codec 方案 (Internal ADC / Analog MIC)

这是成本最低、电路最简单的方案，适用于普通的语音提示、对讲或单麦克风应用。

  • 技术原理：直接利用 T113 芯片内部集成的 3 路 ADC（模数转换器）。麦克风信号（驻极体或模拟 MEMS）通过差分（MICINxP/N）或单端方式接入。
  • 硬件接口：MICIN1P/N, MICIN2P/N, MICIN3P/N 引脚。
  • 特点：
  • 稳定性：极高。由全志原生音频驱动支持，无需额外芯片。
  • 缺点：抗干扰能力较弱，PCB 走线需严格注意模拟地（AGND）隔离，否则容易引入电源噪声或 RF 干扰。
  • 适用场景：对讲机、电梯报站器、普通工业 HMI。

2. 数字麦克风接口方案 (DMIC / PDM)

这是目前智能语音拾音（如智能音箱）的主流方案，尤其是需要麦克风阵列时。

  • 技术原理：使用 PDM（脉冲密度调制）格式输出的数字麦克风。T113 的 DMIC 控制器直接接收数字比特流并进行抽取滤波转换。
  • 关键名词：DMIC (Digital MIC), PDM (Pulse Density Modulation).
  • 接口连接：通常只需 2 根线：DMIC_CLK（时钟）和 DMIC_DATA（数据）。单根数据线在时钟上升/下降沿各传输一路信号，可实现双麦拾音。
  • 特点：
  • 稳定性：高。全数字传输，对 PCB 上的电磁噪声（如 Wi-Fi/4G 信号）极不敏感。
  • 扩展性：T113 最多支持 8 路 数字麦克风输入，非常适合做麦克风阵列（Beamforming 束波成形）。
  • 适用场景：智能家居语音助手、远场拾音设备、会议系统。

3. 外部音频 Codec/ADC 方案 (I2S / PCM)

当内置 ADC 的指标（如信噪比 SNR）无法满足专业级需求，或需要更多输入通道时，会使用此方案。

  • 技术原理：通过 T113 的 I2S/PCM 接口连接外部专业音频芯片（如顺芯 ES7210 负责 4 路采集，或 TI 的 ADC 系列）。
  • 关键名词：I2S (Inter-IC Sound), BCLK (位时钟), LRCK (帧时钟), MCLK (主时钟).
  • 特点：
  • 灵活性：可以选择高性能 ADC 芯片以达到 90dB 以上的信噪比。
  • 复杂性：需要调试外部 Codec 的驱动（通常通过 I2C 进行寄存器配置）。
  • 适用场景：专业录音设备、多路行车记录仪音频采集、高端车载娱乐系统。

4. 单线数字音频方案 (OWA / S/PDIF)

全志芯片特有的 OWA (One Wire Audio) 接口，本质上兼容 S/PDIF 协议。

  • 技术原理：OWA 通过单根信号线传输压缩或非压缩的数字音频数据。
  • 关键名词：OWA (One Wire Audio), S/PDIF (Sony/Philips Digital Interface).
  • 现状：在麦克风开发中，OWA 更多用于**音频输出（TX）**到功放。虽然 T113-S3 支持 OWA RX，但极少有麦克风直接输出该协议，通常用于连接外部数字音频转接盒或光纤音频输入。
  • 适用场景：数字音频处理背板、光纤音频采集。
